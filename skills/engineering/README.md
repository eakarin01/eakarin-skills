# Engineering skills

- **[bump-release](./bump-release/SKILL.md)** — Create a release or hotfix branch with a bumped semantic version, handling stash, source branch, remote rc checks, and push.
- **[code-walkthrough](./code-walkthrough/SKILL.md)** — Walk the user through code an agent just implemented, organised by runtime flow with file:line, so a human reviewer can understand a large change without reading every file.
- **[commit](./commit/SKILL.md)** — Create a git commit in this user's conventional-commit style, scoped from the Jira ticket in the branch name.
- **[pagination-join-safety](./pagination-join-safety/SKILL.md)** — Checklist for paginated list queries that join or load a one-to-many relation, catching row-multiplying join bugs.
- **[sdlc-manager](./sdlc-manager/SKILL.md)** — Orchestrate a full software development pipeline from a raw requirement through tickets, design, coding, review, test, deploy, and monitoring, dispatching each stage to a specialist subagent where one exists.
